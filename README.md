# ⚡ Awesome Digital vCard

A modern, responsive and interactive **digital business card** designed to connect your online professional identity with a printable physical business card.

The project combines contact sharing, QR code generation, UPI payments, contact saving and print-ready business card generation into a single web application.

🌐 **Live Demo:** [https://awesome-digital-vcard.pages.dev/](https://awesome-digital-vcard.pages.dev/)

---

## ✨ Features

### 📱 Digital Business Card

- Fully responsive design
- Works on mobile, tablet and desktop
- Professional personal/business profile
- Custom branding and logo
- Contact information section
- Social media links
- Website and location information

### 📇 Save Contact

- Generates a `.vcf` contact file
- Allows users to save the card owner's contact information
- Uses the native share sheet on supported mobile browsers
- Desktop fallback download supported

### 🔗 Share

- Share the digital card using the device's native sharing system
- Works across supported mobile and desktop browsers
- Easy link sharing for WhatsApp, messaging apps and other platforms

### 🔳 QR Code

- Automatically generated QR code
- QR code points directly to the digital card
- Custom logo can be displayed inside the QR code
- High error-correction level for better reliability

### 💳 UPI Payment

- Dedicated UPI payment section
- Displays UPI ID
- Copy UPI ID button
- UPI QR code for quick payments
- Designed for Indian clients and businesses

### 🖨️ Print-Ready Business Card

- Built-in print functionality
- Generates a print-ready version of the business card
- Can be saved as PDF directly from the browser
- The generated PDF can be sent directly to a printing shop
- No additional card-design software is required

### 🎨 Customizable

The project is designed so that the card can be customized for different clients.

Client-specific information can be configured through the JavaScript configuration object.

## 🎯 Project Goal

The goal of this project is to create a **single professional identity that works both digitally and physically**.

Instead of maintaining separate digital and physical business cards:

> One digital card → One QR code → One professional identity

The physical card can direct people to the complete digital profile through its QR code.

---

## 🔐 Privacy & Security

This project is primarily a client-side web application.

No account or login is required to view the digital card.

Sensitive client information should not be placed directly into the source code if it is intended to remain private.
